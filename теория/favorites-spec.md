# Избранное (favorites) — спецификация MVP

## Цель

Пользователь может сохранять понравившиеся практики и в любой момент открыть **конкретную** практику из личного списка. Раздел доступен во всех режимах (Daily, Challenge, By mood) и не привязан к фильтрам By mood.

Фильтр «случайная из избранного» в By mood — **не входит** в MVP (возможное расширение позже).

---

## 1. Добавление и удаление под практикой

### Где показывается

Кнопки под **всеми** сообщениями с основной практикой:

- Daily (рассылка по расписанию)
- Challenge
- By mood (все фильтры, «Сам решу»)
- «Ещё практики» (Daily)

Бонусные практики — **без** кнопки избранного (только основные).

### Раскладка кнопок (один ряд)

```
[ В избранное 🧡 ]   [ Я сделал ✅ ]
```

Если практика уже в избранном:

```
[ Удалить из 🧡 ]   [ Я сделал ✅ ]
```

### Поведение переключателя

| Действие | Ответ бота (toast / короткое сообщение) | Кнопка после |
|----------|----------------------------------------|--------------|
| Добавить | «Добавил практику в избранное 🧡<br>Ищи этот раздел в меню ↙️» | «Удалить из 🧡» |
| Удалить | «Удалил практику из избранного» | «В избранное 🧡» |

### Снятие кнопок с прошлого сообщения

При отправке новой практики кнопки с предыдущего сообщения снимаются (как сейчас для «Я сделал ✅»). Состояние избранного хранится в базе; при повторной выдаче той же практики кнопка сразу показывает «Удалить из 🧡».

## 2. Раздел «Избранное» в меню

### Команда

| Команда | Подпись в меню Telegram |
|---------|-------------------------|
| `/favorite` | 🧡 Избранное |

Добавить в `app/bot_commands.py` рядом с `/progress`, `/donate` и т.д.

### Пустой список

```
У тебя пока нет избранных практик.
Нажми В избранное 🧡 под любой понравившейся практикой — и она появится здесь.
```

### Непустой список

```
🧡 Твои любимки

[ Лена · Утренняя виньяса 15 мин ]
[ Канал · Йога для сна 20 мин ]
[ Канал · Растяжка спины 12 мин ]

        [ ⬅️ ]  [ 1/1 ]  [ ➡️ ]
```

- **Порядок:** по дате добавления, **новые сверху**
- **Текст кнопки:** `{канал} · {название} {N} мин`
  - Канал — `channel_name`
  - Название — поле `title` из каталога практик
  - Длительность — `time_practices`
  - Пример: `Лена · Утренняя виньяса 15 мин`
  - Если текст не помещается в лимит Telegram (~64 символа на кнопку) — обрезать название с «…», канал и длительность по возможности сохранить
- **Пагинация:** по 5–7 практик на страницу; стрелки «⬅️» / «➡️» и индикатор «{страница}/{всего}»; на одной странице стрелки неактивны или скрыты

### Выбор практики из списка

Пользователь нажимает кнопку с практикой → бот отправляет **новое сообщение** с практикой в стандартном формате (описание, время, интенсивность, канал, ссылка YouTube) и кнопками:

```
[ Удалить из 🧡 ]   [ Я сделал ✅ ]
```

(или «В избранное 🧡», если между открытием списка и выбором практику удалили из другого места)

### «Я сделал ✅»

Нажатие **считается** в общий прогресс (как для практик из By mood / «Ещё практики»): streak, счётчик выполненных, напоминания — по существующей логике `practice_done`.

## 3. База данных

Новая таблица `user_favorites`:

| Поле | Тип | Описание |
|------|-----|----------|
| user_id | BIGINT | Пользователь |
| practice_id | INTEGER | FK → `yoga_practices.practices_id` |
| added_at | TIMESTAMP | Когда добавил (для сортировки) |

Ограничение: `UNIQUE (user_id, practice_id)`.

При удалении практики из каталога — каскадное удаление записей из избранного (или исключение из выборки списка).

## 4. Технические точки интеграции

| Место | Изменение |
|-------|-----------|
| `app/keyboards.py` | Клавиатура практики: `practice_id` + флаг «в избранном» |
| `app/by_mood/send_utils.py` | Новая клавиатура вместо `get_practice_done_keyboard()` |
| `app/schedule/scheduler.py` | То же для Daily / Challenge |
| `app/daily/extra_practices.py` | То же для доп. практик |
| `app/handlers/favorites.py` | `/favorite`, список, пагинация, выдача практики |
| `app/main.py` | Регистрация command + callback handlers |
| `data/postgres_db.py` | Таблица + CRUD: add, remove, is_favorite, list_favorites |
| `app/bot_commands.py` | Команда `favorite` |

### Callback data (черновик)

- `fav_toggle:{practice_id}` — добавить / убрать под сообщением с практикой
- `fav_pick:{practice_id}` — выбрать практику из списка
- `fav_page:{page}` — пагинация списка

## 5. Вне scope MVP

- Кнопка «Избранное» в reply-клавиатуре By mood
- Случайная практика из избранного (фильтр By mood)
- Сортировка внутри раздела (по времени, алфавиту)
- Избранное для бонусных практик
- Редактирование списка из раздела `/favorite` без открытия практики (удаление только через кнопку под практикой)
