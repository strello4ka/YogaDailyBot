# Реакции на практики

## Интерфейс

Под основной практикой:

```text
[ 👍 ] [ 👎 ] [ 🩶/🧡 ]
[      ✅ Я сделал!      ]
```

После снятия кнопки «Я сделал!» верхний ряд остаётся. Логика выполнения и
избранного не меняется; для сердца меняется только UI: `🩶` вне избранного и
`🧡` в избранном.

## Поведение реакций

- Кнопки 👍 и 👎 всегда выглядят одинаково.
- Нажатие 👍 сохраняет `like` и показывает toast `👍 Запомнил, тебе понравилось`.
- Нажатие 👎 сохраняет `dislike` и показывает toast `👎 Понял, не зашло`.
- Повторное нажатие той же реакции не создаёт дубль.
- Противоположная реакция заменяет предыдущую.
- У пользователя хранится одна текущая реакция на сочетание практики и каталога.
- При полном подтверждённом перезапуске реакции пользователя удаляются.

Реакции показываются для основных практик Daily, Challenge, By mood, «Ещё
практики» и в карусели `/favorite`. На подбор практик они пока не влияют.

## Статистика

Служебная команда `/reaction_stats` доступна только администратору и показывает
уникальные лайки и дизлайки по практикам. Общие счётчики пользователям не
показываются.
