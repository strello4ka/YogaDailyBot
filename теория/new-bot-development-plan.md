# Разработка сценария без видимых режимов

Статус: реализованы меню, основной онбординг и экраны Challenge. Интеграционная
проверка тестового бота и часть Rich UI ещё не завершены.
Изменения только локальные; бот не запускался, подключения к базе не выполнялись.
Каталоги и внутренние режимы сохраняются. Спецификация: `new-bot-scenario-spec.md`.

## Выполнено

- Новый порядок команд меню; старые прямые команды пока сохранены.
- «Помощь и советы»: родительский экран, переходы в существующие функции,
  удалён пятый пункт FAQ.
- «Расписание»: экран, существующие изменение времени и пауза через inline-кнопки.
- «Расписание челленджа»: только для участников, повторная проверка участия
  при нажатии старой кнопки, показ сохранённого опубликованного текста.
- Воскресная отправка сохраняет текст после успешной публикации в существующее
  хранилище system_state с ключом группы, даты старта и стартовой практики.
  Схема базы не менялась. Старые публикации автоматически не восстановятся.
- «Получить практику»: текст инструкции; поддержка видео через
  `context.bot_data['practice_keyboard_tutorial_video']`. Видео не предоставлено
  и не подключено; пока отправляется только текст.
- Обработчик быстрых фильтров допускает daily, by_mood и challenge, не меняя режим.
- Первый пункт называется «Управление подпиской», но открывает существующие донаты.
- Новый онбординг хранит этапы в system_state, поддерживает пропуск расписания,
  настройку времени, напоминания 1/24 часа и автозавершение через 72 часа.
- Пользовательское соглашение отправляется Rich Message; URL пока намеренная
  заглушка https://example.com/ и перед тестированием юридической части заменяется.
- Завершение Challenge больше не предлагает режимы: отправляется новое сообщение
  с общей клавиатурой. Начало Challenge использует новые тексты и дату старта.
- После успешного «Я сделал!» кнопка остаётся видимой и disabled; на старых
  просроченных сообщениях сохраняется прежнее снятие кнопки.
- «Сам решу» использует Rich Message на трёх этапах и показывает уже выбранные
  параметры; при ошибке поддержки API автоматически используется прежний inline UI.
- «Мой прогресс» отправляется структурированным Rich Message; у участника
  Challenge появляется визуальная полоса N/28. Расчёты и сброс не менялись.
- Если участника добавили в Challenge во время незавершённого онбординга,
  Challenge сохраняется как ожидающий и продолжается после финального экрана.

## Необходимые решения и материалы

- URL пользовательского соглашения и версия документа.
- Подписка в первом релизе: реальные оплата/ограничения или донаты; нельзя
  показывать обещание двух недель платного доступа без соответствующей логики.
- Видеоинструкция по раскрытию клавиатуры.
- Расписание без ранее настроенного времени; связь онбординга и вступления
  в Challenge; поведение существующих пользователей при переходе.
- Уточнение: нейтральный fallback при отсутствии публикации сейчас реализован
  как «Расписание челленджа пока не опубликовано.».

Не запускать текущую промежуточную версию как законченный новый сценарий:
онбординг и часть старых текстов пока остаются прежними.
